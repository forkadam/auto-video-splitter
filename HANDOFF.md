## What's built

### vsplit CLI (v1.0)

Python CLI that scans a folder of personal video clips, detects scene boundaries with PySceneDetect, gates on a human review step, and losslessly splits each file via FFmpeg. Per-file workspaces under `.vsplit/`, manifest-driven, resumable, failure-isolated.

7 stages: `probe → detect → preview → review → plan → split → verify`.
8 CLI commands: `scan, run, status, approve, reset, clean, one, dashboard`.

### vsplit dashboard (v0.2.x – v0.3.x)

Localhost FastAPI server + React/Vite/Tailwind v4/shadcn frontend. Launched via `vsplit dashboard`. Localhost-only (127.0.0.1), no auth, single-user.

Features:
- Workspace list (hybrid collapsible rows) with per-stage status pips.
- **Per-scene thumbnails** in collapsed rows (first frame) and expanded scene strips (all frames).
- **Hover any thumbnail** to peek a 480px-wide zoom preview (shadcn HoverCard).
- Per-row actions: Run / Reset / Clean / Open preview ↗.
- **"Open preview" now actually works** — server-side `webbrowser.open()` opens the file:// URI in the OS default browser (bypasses the http→file:// click block).
- Bulk selection + filter bar (status / stage / slug glob — same grammar as the CLI).
- Failed-stage log drawer (click a red pip).
- Config drawer: structured form for common fields + collapsible raw-YAML pane, validated server-side via Pydantic.
- Live status updates via Server-Sent Events; both in-process action callbacks and a manifest-mtime watcher thread feed the broker.
- **Modern dark theme** (OKLCH colors, indigo primary, layered surfaces, subtle ambient gradient).
- **Inline `cuts.json` editor** in a drawer — per-scene `keep` / `label` / `merge_with_next`, with thumbnails. Save persists; Save & continue does PUT → approve → run.
- **Next-action pill** on the collapsed row — color-coded by urgency, clickable as a shortcut to the most likely next action (`Run: <stage> →`, `Review & approve →`, `Retry: <stage> →`, `Running: <stage>…`, `Done`).
- Standalone Approve button removed from the row (Save & continue replaces it). Batch Approve remains in `BatchActionBar`.

## How to use it

```powershell
# Toolchain
uv venv
uv pip install -e ".[dev]"

# CLI
uv run vsplit --help
uv run vsplit scan ~/some-folder
uv run vsplit run
uv run vsplit run                          # finishes plan/split/verify after editing cuts.json
ls .vsplit/workspaces/*/output/

# Single-file shortcut
uv run vsplit one ~/Birthday.mov --auto-approve

# Dashboard
uv run vsplit -w ~/some-folder dashboard   # opens http://127.0.0.1:8765 in your browser

# Tests
uv run pytest -q                           # 140 passed
uv run python tests/fixtures/make_fixtures.py  # one-time fixture generation
```

## Known deferred items

See `~/.claude/projects/D--workspace-auto-video-spliter/memory/project_deferred_tech_debt.md` for the full list. Highlights:

- **Hygiene:** Version string still duplicated between `pyproject.toml` and `src/vsplit/__init__.py` — both at `0.2.1` now (resolved on release), but bumps are manual. Hatchling dynamic version is the proper fix. No `.gitattributes`; `[tool.ruff.lint]` config is sparse.
- **Subprocess cancellation:** Only `split` polls `cancel_event` between segments; others run full ffmpeg/ffprobe subprocesses without listening.
- **No subprocess timeouts:** Hung ffmpeg/ffprobe blocks the worker indefinitely.
- **Dashboard:** Inline `cuts.json` editor is still out of scope (use a text editor); no Playwright e2e tests on the React frontend; concurrent multi-user editing of config is last-writer-wins.
- **Tailwind v4 + shadcn:** Vendored components depend on shadcn-the-CLI conventions; future shadcn updates may need manual patching. The shadcn CLI's `@/`-literal-directory bug surfaces every time we `add` a component (workaround: move the file by hand).
- **`run_finished` SSE event** now reports actual `ok` (reading manifest post-dispatch), but per-stage failure events aren't emitted — frontend has to re-fetch to see partial failures.
- **Test coverage gaps in dashboard:** No tests for `--dry-run` equivalents, batch run-with-options, or front-end logic.

## Notable bug fixes worth remembering

Across all three releases. The fixes themselves are in the code; the *root causes* are useful to know if similar work happens later:

**v1 (CLI):**
- Slug edge cases: `slugify('<>:.mp4')` returned `""`; control chars passed through; truncation could leave trailing hyphen; `resolve_collision` could exceed MAX_LEN.
- Path-length estimate underestimated: deepest tail is `output/<slug>-highlight-NN-label.mp4`, not `preview/images/scene-XXX-XX.jpg`.
- Config global layer missing: plan omitted the `~/.config/vsplit/config.yaml` layer that spec §3.4 requires.
- Preview ffmpeg fails seeking to exactly `end_time` on short scenes; clamped to `end_time - ε`.
- Plan stage CSV parsing: Windows ffprobe emits SEI message annotations alongside `pts_time`; CSV parser now splits on `,` and takes the first field.
- Pipeline logger leak: removed `FileHandler`s were never closed; blocked log file re-creation on Windows.

**v0.2 (dashboard MVP):**
- `EventBroker.subscribe` async-generator + Python 3.13: PEP 479 + `asyncio.wait_for(anext(gen))` cancellation permanently closes the gen. Rewrote as a lazy-registering class iterator.
- SSE testing via `TestClient.stream()` blocks the event loop on infinite streams; tests use real uvicorn in a thread + httpx streaming instead.
- `run_finished` event must reflect actual outcome — initial impl hardcoded `ok: True`.
- Slug validation gap on detail/log endpoints; path-traversal-style slugs reached `workspace_dir()` before any check.
- `vsplit dashboard` test infrastructure required `httpx` in dev deps (for FastAPI's TestClient).
- Tailwind v4 not v3: no config file, uses `@tailwindcss/vite` plugin + CSS-based config.
- shadcn `toast` deprecated → `sonner` substituted (and patched to remove its `next-themes` dependency).

**v0.2.1 (dashboard polish):**
- **shadcn theme CSS variables in raw HSL channels are invisible to Tailwind v4.** `var(--popover)` resolved to `"222.2 84% 4.9%"` (plain text), not a color, so `bg-popover` painted nothing. The Select dropdown rendered transparent. Fix: rewrite all theme tokens as `oklch(...)` values, which Tailwind v4 understands natively.
- **Browsers block click navigation from http:// to file://** without an error. The "Open preview" link looked clickable but did nothing. Fix: backend `POST /api/workspaces/{slug}/open-preview` calls Python `webbrowser.open(file_uri)`, which talks to the OS shell handler — bypasses the browser link restriction.
- shadcn CLI keeps creating components under a literal `@/` directory (path alias not resolved during install). Manual move needed after every `shadcn add`.

**v0.3.0 (cuts editor):**
- **iPhone MOV split failed with ffmpeg EINVAL (-22).** Root cause: iPhone MOVs carry two `mebx` Core Media Metadata data streams that MP4 cannot hold; `-map 0 -c copy` tried to copy them and ffmpeg aborted. Fix: `-map 0 -map -0:d` drops all data streams.
- **Dashboard Ctrl+C hung indefinitely.** Browser's SSE keep-alive prevented uvicorn's graceful shutdown. Fix: `timeout_graceful_shutdown=5` so straggling connections are force-closed after 5s.
- **`Pydantic ValidationError.ctx` holds live `ValueError`s from field validators**, which FastAPI's JSON encoder can't serialize. Both `get_cuts` and `put_cuts` use `e.errors(include_context=False)` to strip the offending `ctx`.
- **Radix Drawer auto-closes on outside-click before our `window.confirm` returns.** Solution: controlled `forceOpen` state, re-asserted via `requestAnimationFrame` on confirm-abort.
